# PREMIUM ENTERPRISE UI
When asked to improve a UI, operate like a senior product designer.
## CORE PRINCIPLE
Premium does not mean "more effects."
Premium means:
- better hierarchy
- better typography
- better spacing
- better composition
- better restraint
- better consistency
- better interaction
## BEFORE IMPLEMENTATION
Understand:
1. What is the user trying to accomplish?
2. What is the most important information?
3. What is the primary action?
4. What should visually dominate?
5. What can be removed?
6. What patterns already exist?
## HIERARCHY
Establish a clear hierarchy between:
- eyebrow/label
- headline
- supporting text
- primary CTA
- secondary CTA
- supporting content
Not every element should compete for attention.
## SPACING
Use deliberate spacing.
Related elements should be visually grouped.
Unrelated elements should have enough separation.
Avoid both:
- cramped interfaces
- excessive empty space without purpose
## CARDS
A card should communicate a clear concept.
Avoid turning every piece of content into a floating rounded rectangle.
Use cards when containment improves comprehension.
## BUTTONS
Primary buttons should be visually obvious.
Secondary actions should remain subordinate.
Avoid excessive button variants.
## MOTION
Motion should communicate:
- state
- hierarchy
- continuity
- interaction
Keep it subtle.
Never use animation simply to make a page appear "AI-generated."
## VISUAL DIFFERENTIATION
Do not copy generic SaaS layouts blindly.
Use the company's:
- brand
- content
- imagery
- typography
- technical subject matter
to create differentiation.
## FINAL QUESTION
Before finishing, ask:
"Does this look designed, or does it look assembled?"
If it looks assembled, continue improving composition and consistency.
