# VISUAL AUDIT
You are performing a senior-level visual design review.
Do not immediately modify code.
First inspect the rendered website.
## OBJECTIVE
Determine why the interface does or does not feel:
- premium
- coherent
- trustworthy
- polished
- usable
- visually intentional
## AUDIT ORDER
Review in this order:
### 1. First impression
Evaluate:
- overall visual quality
- brand perception
- hierarchy
- clarity
- trust
- differentiation
Ask:
"What would a prospective enterprise customer think within five seconds?"
### 2. Layout
Inspect:
- section proportions
- alignment
- whitespace
- container widths
- grid consistency
- vertical rhythm
- density
### 3. Typography
Inspect:
- heading hierarchy
- font sizes
- line heights
- text width
- weight
- contrast
- wrapping
### 4. Color
Inspect:
- primary/secondary colors
- contrast
- accent usage
- gradients
- visual noise
- consistency
### 5. Components
Inspect:
- cards
- buttons
- navigation
- forms
- badges
- icons
- CTAs
Look for inconsistent variants.
### 6. Imagery
Inspect:
- quality
- consistency
- composition
- cropping
- art direction
- relevance
- relationship to the UI
### 7. Interaction
Inspect:
- hover
- focus
- active
- transitions
- feedback
- affordances
### 8. Responsive behavior
Inspect:
- desktop
- tablet
- mobile
Look for:
- awkward wrapping
- overflow
- excessive spacing
- compressed layouts
- poor image crops
- inaccessible controls
## OUTPUT
Rank findings:
P0 = seriously damages experience
P1 = major quality issue
P2 = noticeable improvement
P3 = polish
For each issue provide:
- location
- problem
- why it matters
- recommended solution
Do not recommend changes merely because they are fashionable.
Prioritize improvements with the greatest impact on perceived quality and usability.
## IMPORTANT
Do not treat each page independently.
Look for systemic problems.
If five cards have the same problem, fix the card system rather than five individual cards.
If imagery across the site is inconsistent, establish an image system rather than replacing one image.
If spacing is inconsistent, fix the spacing system rather than tweaking individual margins.
Think in systems.
