# Licensed visual sources (private)

This tree holds **purchased / licensed editable source packs** for Digerati Experts marketing visuals.

## Rules

1. **Never** place `.blend`, `.obj`, `.fbx`, PSD, texture source packages, or original ZIPs under `client/public/`, `public/`, or any folder that is copied into a public web root.
2. Only **website-ready derivatives** (optimized AVIF / WebP / PNG, approved GLB, etc.) may be published later under a controlled public path.
3. Keep the **original purchase ZIP** under each pack’s `ORIGINAL/` folder.
4. Large source binaries are **gitignored** — do not force-add them to git.
