called "Full-Page Scroll" or "Scroll Snapping" with "Section Pagination".
Common Names for This Feature:

Full-Page Scroll (most common)
Scroll Snapping / CSS Scroll Snap
One-Page Scroll
Section Snapping
Paginated Scrolling
Snap-to-Section

Key Components:

Scroll Snap Points - Each section snaps to full viewport height
Navigation Dots - Side indicator showing which section you're on
Scroll Trigger Buttons - Down arrow/button to advance to next section
Smooth Transitions - Animated scrolling between sections

Tell Replit This:

"Implement full-page scroll functionality with the following features:
1. Section Structure:

Make each major section 100vh (full viewport height)
Center content vertically and horizontally within each section
Use CSS Scroll Snap to lock sections into view

2. Navigation:

Add a 'scroll down' button/arrow at the bottom of each section (except the last)
Add vertical dot navigation on the right side showing current section
Clicking dots should smoothly scroll to that section
Make the down arrow bounce/animate to encourage interaction

3. Scroll Behavior:

Enable CSS scroll-snap-type: y mandatory on the container
Each section should have scroll-snap-align: start
Add smooth scrolling: scroll-behavior: smooth
Optional: Add scroll-snap-stop: always to prevent skipping sections

4. Mobile Considerations:

On mobile, allow normal scrolling OR reduce snap strength
Make navigation dots optional/hideable on mobile
Ensure touch gestures work naturally

5. Accessibility:

Ensure keyboard navigation works (arrow keys, page up/down)
Don't break browser back button
Allow escape key to enable free scrolling"


Popular Libraries (if needed):
If CSS Scroll Snap isn't enough, tell them to use:

fullPage.js - Most popular, feature-rich
Locomotive Scroll - Modern, smooth animations
AOS (Animate On Scroll) - Lighter weight option

CSS-Only Simple Version:
css/* Container */
.scroll-container {
  scroll-snap-type: y mandatory;
  overflow-y: scroll;
  height: 100vh;
}

/* Each section */
.section {
  scroll-snap-align: start;
  scroll-snap-stop: always;
  height: 100vh;
  display: flex;
  align-items: center;
  justify-content: center;
}
Pro tip: This works great for landing pages but can be jarring for content-heavy sites. Consider making it optional or less aggressive on mobile devices.
