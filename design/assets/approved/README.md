# Approved Asset Sources

This folder records source material that has passed licensing and brand review. Approval here does not mean the original file should be served publicly.

Production use still requires an optimized derivative under `client/public/images/` or `client/public/video/`, an associated provenance note, and rendered QA in the actual component.

Do not copy licensed ORIGINAL assets into public paths. Preserve the source/license record so future maintainers can verify continued usage rights.
