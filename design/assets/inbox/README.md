# Asset Inbox

Use this location for candidate references and temporary review notes only. An inbox item is not approved for production use.

For every externally sourced candidate, create a matching provenance record in `../source-notes/` from `TEMPLATE.md` before promoting it.

Do not put watermarked previews, uncertain-license assets, or licensed originals into public web directories. Keep provider originals/source packages in their designated non-public asset location and publish optimized derivatives only after approval.
