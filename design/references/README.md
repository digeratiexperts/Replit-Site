# References

Place design inspiration here (screenshots, link notes). Not approved for shipping until moved to `../approved/` after DE review.

## How to use

Drop quality-bar screenshots into the folders below. Do **not** copy Linear, Stripe, or other product UIs. Analyze principles (hierarchy, spacing, restraint, composition, motion) and apply them in Digerati’s brand language (`BRAND.md`, `DESIGN_SYSTEM.md`).

Ship-quality DE examples already live in `../approved/`. Anti-patterns live in `../rejected/`.

| Folder | Drop |
|--------|------|
| `typography/` | Type hierarchy, pairing, and density references |
| `layouts/` | Section rhythm, grids, page architecture |
| `cards/` | Card composition (not “card everything”) |
| `imagery/` | Art-direction stills that match the sculpture system |
| `interactions/` | Hover, focus, motion, and state examples |

Prefer descriptive filenames, e.g. `homepage-hero-fullbleed-2026-08.png`, plus a sibling `.md` with 2–5 bullets on **why** it works (principles), not what to clone.
